\subsection{Other controllers}\label{other}

The extension is written for the Mackie Control Universal, but can be used
also with other controllers that support the MIDI protocol of the MCU. For
example, the ``Use keyboard modifier'' option in the \mcu Control Surface
Settings (see section~\ref{settings}) is useful for controllers without
dedicated modifier buttons. The following setup guides describe how to
connect and configure two popular Behringer controllers.
