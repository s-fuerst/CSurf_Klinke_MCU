\subsection{Mailing List / ``Support''}
You can subscribe at \url{https://www.freelists.org/list/mackie_csurf_klinke}
to a mailing list that will be only used to send notifications about
updates.
To communicate with other users you can use the Reaper Forum,
e.g. via this thread
\url{http://forum.cockos.com/showthread.php?t=171827}.
And an issue tracker can be found at
\url{https://github.com/s-fuerst/CSurf_Klinke_MCU/issues}.

\subsection{AI-Assisted Development}
Since version 0.9.5, the development of the extension takes place with
the aid of AI/LLMs. If this bothers you, the last version developed
without AI support is 0.9.1.3, which can be downloaded from
\url{https://sync.luckycloud.de/d/a1228aa877344415}. Please note
that this version is Windows-only and does not include the extender
support introduced in version 0.9.5.

Writing the plugin was a lot of work (but also fun most of the time),
writing this manual too (without the fun part). So acknowledgments in the

\href{https://www.paypal.com/cgi-bin/webscr?cmd=_s-xclick&hosted_button_id=LR54GZHGL6VHA}{here}

does not have an internet connection, you can also send the donation via
