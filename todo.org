** TODO PlugMode: select buttons per unit should map to plugin ranges 1-8, 9-16, ...
   The Select buttons on the different units currently always show the same

** TODO PlugMode: disabled-plugin Select blink only works on unit 1
   When a plugin is disabled, its Select button should blink very slowly
   (brief off intervals, longer on). This works on unit 1 but not on unit 2.
   Possibly related to "Emulate blinking LED", which must be enabled for
   unit 2 and unit 3.
** TODO Optimize DisplayHandler::sendDifferences()
   Re-introduce diffing against m_pHardwareState (currently maintained in
   sendToHardware() but never read): only send the changed runs, each still
   chunked (CHUNK=4) to stay under the JACK/MIDI SysEx fragmentation
   threshold. Today the whole row is always re-sent (14 SysEx per 55-char
   row per update); a fader value change (a few chars) should cost a few
   chars, not the whole row.
   Context: the diff-based rework by Rothchild caused garbled/stale
   displays on the QConPro X and was reverted (commit 35bf711); the
   current whole-row chunked strategy is documented in
   ai-docs/Linux-Port-Changes.md section 4.2. The original diff algorithm
   lives on the master branch in DisplayHandler.cpp::sendDifferences().
   Careful with: switchRows() row-swapping (diff must compare logical
   rows while sendToHardware stores hardware rows), the 0x01 invalid-text
   init, and the memset in switchTo().
