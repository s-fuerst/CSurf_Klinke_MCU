** DONE Optimize DisplayHandler::sendDifferences()
   Re-introduce diffing against m_pHardwareState: only send the changed
   runs, each still chunked (CHUNK=4) to stay under the JACK/MIDI SysEx
   fragmentation threshold. Implemented 2026-07-21: sendDifferences() now
   diffs the logical row against m_pHardwareState (read at the HARDWARE row
   index to mirror switchRows(), which sendToHardware applies before writing
   the state), finds maximal changed runs, and sends each run in 4-byte
   SysEx chunks. A one-field value change costs one short run, not the whole
   row. Correctness anchors preserved: 0x01 invalid-text init (forces first
   paint), the memset in switchTo(), and sendToHardware updating
   m_pHardwareState for every byte emitted (keeps the diff accurate, incl.
   after the Schaltmix-handoff blanking in csurf_mcu.cpp). The stale
   'whole-row' comment in csurf_mcu.cpp was rewritten; see ai-docs
   Linux-Port-Changes.md 4.2.
